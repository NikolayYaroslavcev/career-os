# This directory is historical, not active

This ADR set (`ADR-001` through `ADR-010`, `ADR-009` missing) is an earlier,
abandoned parallel attempt with different numbering and titles than the
active set. It was superseded and is no longer maintained.

**Active ADRs live in `/adr/` at the repo root — see
[`/adr/README.md`](../../adr/README.md) for the full explanation and where
to add new ADRs.**

Do not add new files to this directory.
